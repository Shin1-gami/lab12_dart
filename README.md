# Кулінарна книга рецептів

Консольний застосунок, розроблений мовою Dart для лабораторної роботи 1-2.

## Можливості

- перегляд списку рецептів;
- додавання рецептів;
- видалення рецептів;
- пошук рецептів;
- сортування за назвою та категорією;
- зміна статусу рецепта;
- отримання рецептів із зовнішнього API;
- збереження даних у JSON;
- автоматичне завантаження даних під час запуску;
- модульне тестування.

## Використані технології

- Dart;
- HTTP;
- JSON;
- TheMealDB API;
- пакет test.

## Використане API

TheMealDB:

https://www.themealdb.com/api.php

Приклад запиту:

https://www.themealdb.com/api/json/v1/1/search.php?s=pasta

dart run bin/main.dart

## Запустити тести:

dart test

dart analyze

dart format .
